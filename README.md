# LLC Resonant Converter Simulation in MATLAB/Simulink

This repository contains a high-efficiency **DC-DC LLC Resonant Converter** model designed and simulated using MATLAB & Simulink (Simscape Electrical). 
For a detailed step-by-step design guide, parameter calculations, and simulation results analysis, watch the full video tutorial below:

[![Watch the Tutorial Video](https://youtube.com)](https://youtube.com)


* **Soft-Switching Topology:** Implements Zero Voltage Switching (ZVS) for primary MOSFETs and Zero Current Switching (ZCS) for secondary rectifier diodes.
